# 优化后的图标系统新用法

## 🎯 核心改进一览

| 改进项 | 说明 | 效果 |
|-------|------|------|
| **SVG 优化** | 统一样式，移除硬编码 | 文件体积 -16% |
| **颜色变体** | 7 种预定义颜色 | 快速应用不同风格 |
| **交互增强** | 缩放 + 淡化动画 | 用户体验更生动 |
| **可访问性** | 添加 alt 属性 | 支持屏幕阅读器 |
| **布局优化** | 自动垂直对齐 | 排版更整洁 |

## 🎨 7 种颜色变体

### 1. Primary（主色）
```vue
<app-icon icon="search" color="primary" />
<app-icon icon="directions" color="primary" size="lg" />
```
**用途：** 主要操作、正常状态  
**特征：** 深色，87% 透明度

### 2. Secondary（次色）
```vue
<app-icon icon="info" color="secondary" />
<app-icon icon="help" color="secondary" />
```
**用途：** 次要信息、辅助内容  
**特征：** 浅色，60% 透明度

### 3. Success（成功）
```vue
<app-icon icon="check" color="success" />
<app-icon icon="done" color="success" size="lg" />
```
**用途：** 成功状态、正面反馈  
**特征：** 绿色调

### 4. Warning（警告）
```vue
<app-icon icon="alert" color="warning" />
<app-icon icon="info" color="warning" size="lg" />
```
**用途：** 警告提示、需要注意  
**特征：** 橙色调

### 5. Error（错误）
```vue
<app-icon icon="close" color="error" />
<app-icon icon="delete" color="error" />
```
**用途：** 错误提示、删除操作  
**特征：** 红色调

### 6. Disabled（禁用）
```vue
<app-icon icon="save" color="disabled" />
<app-icon icon="upload" color="disabled" />
```
**用途：** 禁用功能、不可用状态  
**特征：** 灰色，灰度处理

### 7. Inherit（继承）
```vue
<app-icon icon="custom" color="inherit" :custom-style="{ opacity: 0.5 }" />
```
**用途：** 自定义颜色、特殊样式  
**特征：** 不做颜色处理

## 💬 实际使用场景

### 场景 1：表单验证反馈

```vue
<script setup>
import { ref } from 'vue'

const email = ref('')
const isValid = ref(false)

const validateEmail = () => {
	isValid.value = email.value.includes('@')
}
</script>

<template>
	<view class="form-field">
		<input v-model="email" @blur="validateEmail" placeholder="输入邮箱" />
		
		<!-- 根据验证状态显示不同的图标 -->
		<app-icon
			v-if="isValid"
			icon="check"
			color="success"
			size="md"
			alt="邮箱格式正确"
		/>
		
		<app-icon
			v-else-if="email && !isValid"
			icon="close"
			color="error"
			size="md"
			alt="邮箱格式错误"
		/>
	</view>
</template>

<style scoped>
.form-field {
	display: flex;
	align-items: center;
	gap: 8rpx;
}
</style>
```

## 💡 最佳实践

### ✅ 推荐做法
```vue
<!-- 1. 使用预定义颜色 -->
<app-icon icon="check" color="success" />

<!-- 2. 组合使用 size 和 color -->
<app-icon icon="delete" color="error" size="lg" />

<!-- 3. 为可点击图标添加 alt -->
<app-icon icon="edit" clickable alt="编辑" />

<!-- 4. 在按钮中配合使用 -->
<button>
	<app-icon icon="download" color="primary" size="sm" />
	下载
</button>
```

### ❌ 避免做法
```vue
<!-- 1. 避免混用 emoji 和 SVG -->
<view>🔍 <app-icon icon="search" /></view>

<!-- 2. 避免过度自定义 -->
<app-icon icon="icon" :custom-style="{ ... }" />

<!-- 3. 避免忽略可访问性 -->
<app-icon icon="delete" clickable />  <!-- 应加 alt -->
```
