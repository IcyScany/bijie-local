## 🔄 状态转移示例

假设有一个下载按钮，根据不同状态显示不同颜色：

```vue
<script setup>
import { ref, computed } from 'vue'

const downloadStatus = ref('idle')  // idle | downloading | success | error | disabled

const buttonColor = computed(() => {
	switch(downloadStatus.value) {
		case 'idle':
			return 'primary'        // 蓝色 - 可点击
		case 'downloading':
			return 'primary'        // 蓝色 - 处理中
		case 'success':
			return 'success'        // 绿色 - 成功
		case 'error':
			return 'error'          // 红色 - 失败
		case 'disabled':
			return 'disabled'       // 灰色 - 禁用
		default:
			return 'primary'
	}
})
</script>

<template>
	<button :disabled="downloadStatus === 'disabled'">
		<app-icon
			:icon="downloadStatus === 'success' ? 'check' : 'download'"
			:color="buttonColor"
		/>
		{{ downloadStatus === 'downloading' ? '下载中...' : '下载' }}
	</button>
</template>
```

## 💡 快速技巧

### 1. 动态颜色选择
```javascript
const colorMap = {
	'success': 'success',
	'pending': 'warning',
	'error': 'error',
	'disabled': 'disabled'
}

// 使用
const statusColor = colorMap[item.status]
```

### 2. 颜色 + 文本组合
```vue
<!-- 更清晰的状态表示 -->
<view class="status">
	<app-icon :icon="icon" :color="color" size="sm" />
	<text>{{ status }}</text>
</view>
```

### 3. 禁用状态判断
```vue
<app-icon
	:icon="icon"
	:color="isEnabled ? 'primary' : 'disabled'"
	:clickable="isEnabled"
/>
```
