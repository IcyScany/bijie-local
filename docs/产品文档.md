# 毕节生活地图 · 产品文档

## 1. 产品概述

| 项目 | 说明 |
| --- | --- |
| 产品名称 | 毕节生活地图（bijie-local） |
| 一句话简介 | 面向毕节七星关区的生活地图，展示美食、景点与便民设施，支持用户共建与管理员审核 |
| 产品形态 | 微信小程序（uni-app，Vue3 组合式 API）+ uniCloud 云开发 |
| 默认中心点 | 贵州省毕节市七星关区（105.2844, 27.2987） |
| 核心价值 | 聚合本地生活地点、地图可视化、导航直达、用户贡献与审核闭环 |

### 目标用户
- **普通用户**：本地居民与游客，查看地图、搜索地点、一键导航、提交/纠错地点。
- **管理员**：维护地点数据、审核用户提交内容。

### 核心场景
1. 打开地图 → 按分类查看美食/景点/便民厕所等 → 点击查看详情并导航前往。
2. 用户发现新摊位或信息有误 → 通过“补充/纠错”匿名提交 → 管理员审核。
3. 管理员登录 → 搜索地点/地图选点/上传图片 → 新增或修改地点。

---

## 2. 技术架构

- **前端**：uni-app（Vue3 `<script setup>`），跨端，主要运行于微信小程序。
- **后端**：uniCloud（支付宝云空间 `bijie-local-space`），云对象 + 云函数 + 云数据库 + 云存储。
- **地图能力**：`<map>` / `uni.chooseLocation` / `uni.openLocation`；POI 搜索经云函数调用腾讯地图 WebService。
- **登录**：微信 `uni.login` → 云函数 `user-auth` 用 AppSecret 换取 OpenID。

### 资源清单
| 类型 | 名称 | 说明 |
| --- | --- | --- |
| 云对象 | `favorite-spots` | 地点 CRUD、投稿、审核（核心业务） |
| 云函数 | `user-auth` | 微信登录、OpenID 用户信息、管理员校验、Token |
| 云函数 | `place-search` | 腾讯地图 POI 关键字搜索 |
| 数据表 | `favorite-spots` | 地点数据 |
| 数据表 | `users` | 用户信息 |
| 数据表 | `admin-whitelist` | 管理员白名单（OpenID） |
| 工具模块 | `utils/auth.js` | 前端登录态封装（token / isAdmin / userInfo） |

## 3. 功能模块

### 3.1 首页（入口页）
- 品牌区：区域徽标 + 标题 + 副标题。
- 三张功能入口卡片：
  - **打开生活地图** → 地图页
  - **地点管理** → 校验管理员身份后进入（非管理员提示无权限）
  - **我来补充 / 纠错** → 投稿页
- App 启动时静默登录（`ensureLogin`）。

### 3.2 生活地图（pages/map/map.vue）
- 全屏地图，默认中心为七星关区，`show-location` 显示定位。
- **顶部横向滑动分类栏**：全部 / 美食 / 景点 / 便民厕所 / 便民商店 / 其他，按类型显隐标记点。
- **标记点**：携名称气泡（callout），点击弹出详情。
- **底部列表**：地点名称、地址/备注、类型标签；点击定位并打开详情。
- **地点详情弹层**：
  - 名称、类型标签、实拍图片（可点击放大预览）
  - 地址、备注、坐标、**贡献者**
  - **去这里**：调用 `uni.openLocation` 拉起地图导航
- 仅展示 `status = approved`（含历史无状态字段）的地点。
- 页面 `onShow` 自动刷新。

### 3.3 地点管理（pages/admin/favorites.vue，仅管理员）
- **权限**：进入时校验管理员身份，非管理员提示并返回。
- **列表**：卡片展示名称、审核状态标签（待审核/已驳回）、来源标签（用户提交）、类型、图片、地址、纠错说明/备注、坐标、贡献者。
- **筛选**：类型横向筛选 + 审核状态筛选（全部/待审核/已通过/已驳回）+ 名称搜索。
- **新增/编辑表单**：
  - **搜索地点**：关键字经 `place-search` 搜索，点击结果自动填入名称/地址/经纬度（名称默认结果名，可改）
  - **地图选点**：`uni.chooseLocation`，失败时跳转自建选点页
  - **实拍图片**：`uni.chooseImage` + `uniCloud.uploadFile`，最多 9 张，可预览/删除
  - 类型、名称、地址、经纬度、备注
- **审核操作**：待审核项支持“通过 / 驳回”。
- **删除**：二次确认后删除。

### 3.4 补充 / 纠错（pages/contribute/contribute.vue，面向所有用户）
- 顶部切换：**补充新地点** / **纠错反馈**。
- 补充新地点：搜索地点、类型、名称、地址、地图选点、描述、现场图片、联系方式。
- 纠错反馈：选择要纠错的地点 + 纠错说明（可附图片）。
- 提交后进入 `pending` 待审核状态，需管理员通过后才会展示在地图上。

### 3.5 地图选点（pages/location-picker/location-picker.vue）
- 全屏地图 + 屏幕中心**固定准星**。
- 默认初始点为**个人当前位置**（`uni.getLocation`，失败回退七星关区），提供“定位到当前位置”按钮。
- 拖动地图取中心点坐标，确定后通过 `eventChannel` 回传经纬度。

### 3.6 用户与权限体系
- **用户识别**：微信端 `uni.login` 获取 code，`user-auth` 用 AppSecret 调 `jscode2session` 换 OpenID，写入 `users` 表。
- **管理员判定**：OpenID 是否存在于 `admin-whitelist`。
- **初始管理员**：白名单为空时，首个登录用户自动成为管理员（bootstrap）。
- **Token**：`user-auth` 用 HMAC 签发 Token（默认 7 天），前端存本地，管理类操作携带。
- **贡献者溯源**：新增/修改地点时自动记录贡献者 OpenID 与名称，并在展示端体现。

| `create_date` / `update_date` | timestamp | 时间 |

### 5.3 admin-whitelist（管理员白名单）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `openid` | string | 管理员 OpenID |

| `create_date` | timestamp | 时间 |

## 6. 接口 API

### 6.1 云对象 favorite-spots
| 方法 | 参数 | 权限 | 说明 |
| --- | --- | --- | --- |
| `getList` | `{ keyword?, type?, status?, source?, page?, pageSize? }` | 公开 | 分页/筛选/名称模糊搜索 |
| `getDetail` | `id` | 公开 | 详情 |
| `add` | `data, token` | 管理员 | 新增（记录贡献者，状态 approved） |
| `update` | `id, data, token` | 管理员 | 修改（记录最近修改者） |
| `remove` | `id | id[], token` | 管理员 | 删除（支持批量） |
| `submit` | `data, token?` | 公开 | 用户投稿/纠错，状态 pending（登录则记录贡献者） |
| `review` | `id, status, token` | 管理员 | 审核：approved / rejected |

### 6.2 云函数 user-auth
- `login`：参数 `{ code }`（微信）或 `{ openid }`（非微信/开发），返回 `{ token, openid, isAdmin, userInfo }`。
- `check`：参数 `{ token }`，返回 `{ isAdmin, openid }`。
- `updateProfile`：参数 `{ token, nickname?, avatar? }`。

### 6.3 云函数 place-search
- 参数 `{ keyword, region='毕节', page=1, pageSize=10 }`
- 返回 `{ list: [{ title, address, longitude, latitude }], total }`
- 依赖腾讯地图 WebService Key。

## 7. 权限与安全

- **权限模型**：公开读（地点查询、投稿）；管理写（增删改、审核）需 Token → OpenID → 白名单校验。
- **Token**：`user-auth` 与 `favorite-spots` 使用同一 `TOKEN_SECRET` 做 HMAC 验签。
- **数据表权限**：`users`、`admin-whitelist` 关闭客户端直连（仅云函数访问）。
- **配置项**（需在云函数中填写）：
  | 配置 | 位置 | 说明 |
  | --- | --- | --- |
  | `WX_SECRET` | `cloudfunctions/user-auth/index.js` | 微信小程序 AppSecret，用于换 OpenID |
  | `TOKEN_SECRET` | `user-auth` 与 `favorite-spots` | Token 签名密钥，两处需一致 |
  | `TENCENT_MAP_KEY` | `cloudfunctions/place-search/index.js` | 腾讯位置服务 Key（开通 WebServiceAPI） |

## 8. 核心流程

### 8.1 登录与鉴权
```
启动 → uni.login(code) → user-auth → jscode2session → OpenID
→ 写入 users → 校验 admin-whitelist（空则 bootstrap 管理员）
→ 返回 token/isAdmin → 前端存储
```

### 8.2 地点审核
```
用户提交(submit, status=pending) → 管理员管理页筛选“待审核”
→ 通过(review=approved) → 出现在地图 / 驳回(review=rejected)
```

### 8.3 地点新增（管理员）
```
搜索地点/地图选点 → 自动填充 → 上传图片 → 保存(add, 记录贡献者) → 地图展示
```

---

## 9. 状态说明
- 地点审核状态：`pending`（待审核）→ `approved`（已通过）/ `rejected`（已驳回）。
- 地图仅展示 `approved`；管理页展示全部状态。

## 10. 部署与配置清单
1. uniCloud 关联云空间 `bijie-local-space`（支付宝云）。
2. 上传数据库 Schema：`favorite-spots`、`users`、`admin-whitelist`。
3. 上传云对象/云函数：`favorite-spots`、`user-auth`、`place-search`。
4. 填写并上传：`WX_SECRET`、`TENCENT_MAP_KEY`，核对 `TOKEN_SECRET` 一致。
5. 微信小程序：配置 `scope.userLocation` 与 `requiredPrivateInfos`（getLocation、chooseLocation）。
6. H5 端如需地图/定位，需另配地图服务商 Key。

## 11. 已知限制与后续规划

### 已知限制
- 未配置 `WX_SECRET` 时，微信端登录会明确报错；`TENCENT_MAP_KEY` 未配置时地点搜索不可用。
- POI 搜索依赖第三方地图服务配额。
- 部分云端 Schema 字段可能需在 HBuilderX 手动同步上传。

### 后续规划（可选）
- 管理员在应用内直接维护白名单。
- 贡献者排行榜 / 我的贡献记录。
- 地点评论、收藏、评分。
- 图片审核与内容安全校验。
- POI 搜索接入选点页并联动地图定位。
