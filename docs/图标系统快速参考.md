# 图标系统快速参考

## 最常见的三种用法

### 1️⃣ 基础用法：显示图标
```vue
<app-icon icon="search" size="md" />
```

### 2️⃣ 分类图标：按类型获取
```vue
<app-icon :icon="getCategoryIcon(spot.type)" size="lg" />
```

### 3️⃣ 可点击图标：交互式图标
```vue
<app-icon icon="call" size="md" clickable @click="makeCall" />
```

## 颜色变体快速参考

```vue
<!-- Google Blue - 主色 -->
<app-icon icon="search" color="primary" />

<!-- Light Blue - 次色 -->
<app-icon icon="search" color="secondary" />

<!-- Google Green - 成功 -->
<app-icon icon="check" color="success" />

<!-- Google Yellow - 警告 -->
<app-icon icon="alert" color="warning" />

<!-- Google Red - 错误 -->
<app-icon icon="close" color="error" />

<!-- Gray - 禁用 -->
<app-icon icon="lock" color="disabled" />

<!-- 自定义 -->
<app-icon icon="star" color="inherit" />
```

### 颜色变体说明

| 变体 | 谷歌官方色 | 用途 | 特点 |
|------|----------|------|------|
| `primary` | Google Blue (#1A73E8) | 主要操作 | 深蓝，正常透明度 |
| `secondary` | Light Blue | 次要信息 | 浅蓝，降低透明度 |
| `success` | Google Green (#0F9D58) | 成功状态 | 绿色调 |
| `warning` | Google Yellow (#FBBC04) | 警告状态 | 黄色调 |
| `error` | Google Red (#E94335) | 错误状态 | 红色调 |
| `disabled` | Gray | 禁用状态 | 灰色，降低对比度 |
| `inherit` | Custom | 自定义 | 无处理 |

## 常见问题秒答

**Q: 怎么改图标颜色？**
> SVG 文件中修改 `fill` 属性，或通过 CSS 选择器修改

**Q: 怎么添加图标点击事件？**
> 加上 `clickable` 属性和 `@click` 事件处理器

**Q: 怎么使用自定义路径的图标？**
> 直接传入完整路径：`<app-icon icon="/path/to/icon.svg" />`

**Q: 为什么推荐用 AppIcon 而不直接用 image？**
> 因为 AppIcon 提供了尺寸预设、集中管理等便利，更易维护
