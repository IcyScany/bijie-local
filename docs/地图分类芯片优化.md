## 🔧 技术实现

### 新增图标
```
static/icons/hotel.svg          (酒店图标)
static/icons/gas-station.svg    (加油站图标)
```

### 修改的文件
```
pages/map/map.vue              (更新分类配置 + 图标渲染)
styles/google-maps.scss        (优化芯片样式)
utils/icons.js                 (添加新图标映射)
```

### 关键代码

**分类配置：**
```javascript
const categories = [{
  label: '设置住地',
  value: 'all',
  icon: 'location'
}, {
  label: '餐馆',
  value: 'food',
  icon: 'restaurant'
}, {
  label: '酒店',
  value: 'view',
  icon: 'hotel'
}, {
  label: '加油站',
  value: 'toilet',
  icon: 'gasStation'
}, {
  label: '便民商店',
  value: 'shop',
  icon: 'storefront'
}]
```

**图标渲染：**
```vue
<app-icon 
  :icon="item.icon" 
  size="sm"
  :color="category === item.value ? 'inherit' : 'primary'"
  :custom-style="category === item.value ? { opacity: 1, filter: 'brightness(2)' } : {}"
/>
```

## 📱 响应式布局

芯片采用水平滚动设计：

```
┌──────────────────────────────────┐
│ 设置住地 | 餐馆 | 酒店 | 加油... │
│ (可左右滚动)                     │
└──────────────────────────────────┘
```

### 特点
- 水平滚动（`scroll-x`）
- 间距 8rpx（`gap: 8rpx`）
- 自动隐藏滚动条（`:show-scrollbar="false"`）
- 底部内边距（`padding-right: 16rpx`）

## 🚀 使用示例

### 添加新分类

1. 在 `pages/map/map.vue` 的 `categories` 数组中添加新项：
```javascript
{
  label: '停车场',
  value: 'parking',
  icon: 'parking'  // 需要新的图标
}
```

2. 在 `utils/icons.js` 中添加图标映射：
```javascript
parking: '/static/icons/parking.svg'
```

3. 在 `static/icons/` 中创建 SVG 图标
4. 完成！新分类会自动显示

### 改变选中颜色

编辑 `styles/google-maps.scss` 中的 `.gm-chip-map.gm-chip-selected`：
```scss
.gm-chip-map.gm-chip-selected {
  background-color: #YOUR_COLOR;
}
```
