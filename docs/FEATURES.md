# 功能说明文档

## 核心功能模块

### 1. 生活地图（pages/map/map.vue）

主功能页面，提供地图展示、搜索、筛选、排序、收藏、评论等综合地点浏览体验。

#### 1.1 地图区域
- 全屏地图显示，默认中心为毕节七星关区
- 支持自由拖动、缩放、旋转
- 显示用户当前位置（蓝点）
- 底部"回到我的位置"按钮，快速定位

#### 1.2 顶部搜索栏
- **关键字搜索**：后端模糊匹配地点名称/地址
- **搜索历史**：展示最近 5 条搜索记录
- **删除历史**：一键清空搜索历史

#### 1.3 分类筛选
- 横向滑动分类栏：全部 / 美食 / 景点 / 便民厕所 / 便民商店 / 其他
- 点击分类实时过滤地图标记
- 图标颜色与大小自定义

#### 1.4 地图标记
- 每个标记显示地点名称气泡（callout）
- 不同类型显示不同图标
- 地点密集时自动聚合
- 点击标记展示地点详情（半屏）

#### 1.5 底部列表面板（DragSheet）
- 可拖拽的列表面板，支持半屏↔全屏切换
- 每个地点卡片包含：
  - 地点名称、类型标签
  - 地址与距离（根据用户位置实时计算）
  - 平均评分与评论数
  - 最新评论预览
  - 收藏按钮

#### 1.6 排序功能
- **距离排序**：按用户位置升序排列
- **评分排序**：按平均评分降序排列
- **综合排序**：默认按创建时间降序

#### 1.7 地点详情（可切换半屏/全屏）

**概览标签页**
- 地点名称、类型标签
- 实拍图片（支持左右滑动、点击放大预览）
- 地址、备注、坐标、贡献者名称
- **收藏按钮**：显示收藏状态
- **去这里**：调用 `uni.openLocation` 拉起地图导航

**简介标签页**
- 该地点的所有通过审核的评论
- 每条评论显示：用户头像、昵称、评分、评论文字、配图
- 支持点击打开评论详情页

#### 1.8 交互优化
- 拖拽列表时地图保持可操作性
- 从地图标记点击 → 详情半屏
- 从列表卡片点击 → 详情全屏
- 页面 `onShow` 自动刷新数据

### 2. 地点管理（pages/admin/spots.vue）

管理员专属功能，支持地点的完整 CRUD 操作。

#### 2.1 列表视图
- 卡片式展示所有地点
- 展示内容：名称、审核状态、来源、类型、主图、地址、贡献者

#### 2.2 筛选与搜索
- **分类筛选**：按类型筛选
- **审核状态筛选**：全部/待审核/已通过/已驳回
- **来源筛选**：用户提交/管理员新增
- **名称搜索**：关键字模糊搜索

#### 2.3 新增地点
- **方式一**：搜索 POI → 自动填充名称/地址/坐标
  - 调用腾讯地图 `place-search` 云函数
  - 选择搜索结果自动回显
  - 可手动修改
  
- **方式二**：地图选点
  - 跳转至 location-picker 页面
  - 拖拽地图取中心点坐标
  
- **表单字段**：类型、名称、地址、经纬度、备注、联系方式
- **图片上传**：最多 9 张，自动压缩
- **提交**：直接发布（status = approved），自动记录贡献者

#### 2.4 编辑地点
- 支持修改所有字段
- 自动记录修改者与修改时间
- 操作日志可追踪

#### 2.5 审核操作
- **待审核项**：展示用户投稿
  - 通过：status = approved → 发布 → 用户获得积分
  - 驳回：status = rejected → 填写驳回原因
  - 撤销驳回：恢复为 pending
  
- **已通过项**：支持直接编辑

#### 2.6 删除地点
- 二次确认删除
- 级联删除关联的评论与收藏

### 3. 审核管理（pages/admin/review.vue）

管理员审核用户投稿的页面。

#### 3.1 投稿列表
- 展示所有待审核的投稿（补充新地点 + 纠错反馈）
- 区分投稿类型：新增地点 / 纠错反馈

#### 3.2 投稿详情
- 原地点信息（纠错时）
- 投稿说明、图片、联系方式
- 投稿者信息

#### 3.3 审核操作
- **通过**：
  - 新增 → 直接发布为地点，status = approved
  - 纠错 → 合并数据到原地点，status = approved
  - 投稿者 `users.points` += 分值（新增 10，纠错 5）
  
- **驳回**：
  - status = rejected
  - 填写驳回原因
  - 用户可在"我的共创"页看到驳回说明
  
- **撤销驳回**：恢复为 pending

### 4. 补充/纠错（pages/contribute/contribute.vue）

用户提交新地点或纠错反馈的页面，采用谷歌风格设计。

#### 4.1 补充新地点
- **信息输入**：
  - 地点类型（必填）
  - 地点名称（必填）
  - 地址（必填，可通过地图选点）
  - 备注描述（可选）
  - 联系方式（可选）
  
- **定位方式**：
  - 手输地址
  - 地图选点（uni.chooseLocation 或自建选点页）
  
- **图片上传**：
  - 最多 3 张实拍图片
  - 自动压缩处理
  - 支持预览和删除
  
- **提交**：
  - 状态 = pending（待审核）
  - 如已登录，自动记录投稿者 openid/name
  - 如未登录，匿名投稿

#### 4.2 纠错反馈
- **选择地点**：搜索要纠错的地点
- **纠错类型**（预设）：
  - 地址错误
  - 营业时间错误
  - 已关闭/搬迁
  - 联系方式错误
  - 其他
  
- **纠错说明**：详细描述错误信息（必填）
- **证明图片**：可选上传 1-3 张图片
- **提交**：记录投稿者，状态 = pending

#### 4.3 提交流程
- 表单验证（必填项）
- 图片压缩与上传
- 提交确认弹窗
- 成功提示

### 5. 我的共创（pages/contributions/contributions.vue）

用户查看自己的贡献记录与积分。

#### 5.1 共创列表
- 展示用户所有的投稿记录（新增/纠错/评论）
- 每条记录显示：
  - 类型标签（新增/纠错）
  - 地点名称或投稿说明
  - 审核状态（待审核/已通过/已驳回）
  - 获得积分
  - 投稿时间

#### 5.2 积分统计
- 头部展示总积分
- 积分规则说明：
  - 新增地点通过：+10
  - 纠错反馈通过：+5

#### 5.3 共创详情
- 点击卡片查看完整投稿内容
- 展示审核结果（通过/驳回）
- 如驳回，展示驳回原因
- 关联的地点信息

### 8. 地点评论评分

#### 8.1 评论发表
- 在地点详情页添加评论
- 字段：
  - 评分（1-5 星，必填）
  - 评论文字（必填）
  - 配图（可选，最多 3 张，自动压缩）
  
- 默认审核状态 = pending
- 自动记录用户信息（openid、name、avatar）

#### 8.2 评论审核
- 管理员审核后状态变为 approved
- 仅显示已通过的评论

#### 8.3 评论展示
- 地点详情"简介"标签页展示所有通过的评论
- 评论排序：最新优先
- 支持删除自己的评论

#### 8.4 评分聚合
- 自动计算地点的平均评分
- 地点卡片展示评分与评论数
- 用于排序的参考数据

### 9. 用户收藏系统

#### 9.1 收藏操作
- 在地点详情页点击收藏按钮
- 需要登录
- 支持收藏/取消收藏

#### 9.2 收藏数据

#### 9.3 收藏列表

- 支持搜索与筛选
- 支持取消收藏

### 10. 地图选点（pages/location-picker/location-picker.vue）

辅助工具，用于管理员或用户快速选择地点坐标。

#### 10.1 功能
- 全屏地图显示
- 屏幕中心固定准星标记
- 默认初始位置为用户当前位置（失败时回退七星关区）
- 提供"定位到当前位置"按钮

#### 10.2 操作
- 拖拽地图，移动准星到目标位置
- 点击"确定"按钮，通过 `eventChannel` 回传坐标
- 返回上一页自动填充坐标

## 核心业务流程

### 12.1 用户投稿 → 审核 → 发布流程

```
┌──────────────────────────────────────────────────┐
│ 1. 用户提交投稿（补充/纠错）                        │
│    - 补充：新增地点投稿                             │
│    - 纠错：针对现有地点的纠错反馈                    │
│    - status = pending                           │
└──────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────┐
│ 2. 管理员审核列表                                  │
│    - 展示所有 pending 状态的投稿                   │
│    - 审核信息：投稿类型、内容、图片、联系方式        │
└──────────────────────────────────────────────────┘
                       ↓
                   ┌───┴───┐
                   ▼       ▼
         ┌──────────┐   ┌────────┐
         │ 通过审核 │   │ 驳回   │
         └──────────┘   └────────┘
              ↓              ↓
         ┌──────────┐   ┌────────┐
         │发布地点  │   │记录   │
         │status=  │   │驳回原因│
         │approved │   │通知用户│
         └──────────┘   └────────┘
              ↓
         ┌──────────┐
         │ 用户积分 │ (+10 新增 / +5 纠错)
         │+积分    │
         └──────────┘
              ↓
         ┌──────────┐
         │地图展示  │
         │地点发布 │
         └──────────┘
```

### 12.2 评论审核流程

```
用户发表评论 → 记录到 spot-comments(status=pending)
    ↓
    ├─ 自动更新 spots 表的 rating_count 与 average_rating
    ↓
管理员审核 → status = approved
    ↓
地点详情页"简介"标签页展示评论
    ↓
重新计算地点平均评分
    ↓
地点卡片同步更新评分与评论数
```

### 12.3 收藏流程

```
用户点击收藏 → 检查登录状态
    ↓
已登录 → 插入 spot-favorites 表
    ↓
显示"已收藏"状态
    ↓
用户可在"我的收藏"页查看
    ↓
取消收藏 → 删除记录
```

## 数据一致性

### 13.1 关键字段同步

| 操作 | 关联更新 |
| --- | --- |
| 新增/编辑评论 | `spots.rating_count`、`average_rating` 重新计算 |
| 删除评论 | `spots.rating_count`、`average_rating` 重新计算 |
| 批量删除地点 | 级联删除关联的评论与收藏 |
| 用户信息修改 | 同步更新所有已发表的评论记录 |

### 13.2 事务保证

- 使用 uniCloud 云函数事务能力确保操作原子性
- 关键操作（审核、删除）添加日志记录

## 性能优化

### 14.1 列表分页
- 默认每页 20 条记录
- 支持自定义分页大小

### 14.2 搜索优化
- 后端模糊搜索（使用正则表达式或 MongoDB 全文索引）
- 搜索结果缓存（可选）

### 14.3 图片处理
- 前端自动压缩（宽度不超过 800px）
- 支持多倍图上传

### 14.4 距离计算
- 后端基于经纬度 Haversine 公式计算
- 返回实时距离数据，支持排序
