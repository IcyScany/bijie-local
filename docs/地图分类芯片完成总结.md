### 1. 胶囊形设计

### 2. 交互反馈
```
悬停时：
  • 背景变浅灰
  • 边框颜色加深
  • 阴影增强

按下时：
  • 背景色加深
  • 缩放到 96%
  • 阴影进一步加深

选中时：
  • 背景变为 Google Blue
  • 文字 + 图标变白
  • 阴影蓝色调
```

### 3. 图标处理
```
未选中：
  • 使用 color="primary" (灰色)
  • 透明度 87%

选中时：
  • 使用 color="inherit"
  • 应用 brightness(2) filter
  • 显示为白色
```

## 🚀 扩展指南

### 添加新分类

**步骤1：** 编辑 `pages/map/map.vue`
```javascript
{
  label: '停车场',
  value: 'parking',
  icon: 'parking'
}
```

**步骤2：** 编辑 `utils/icons.js`
```javascript
parking: '/static/icons/parking.svg'
```

**步骤3：** 创建 SVG 图标
```
static/icons/parking.svg
```

**步骤4：** 完成！新分类自动显示

### 改变选中颜色

编辑 `styles/google-maps.scss`：
```scss
.gm-chip-map.gm-chip-selected {
  background-color: #YOUR_NEW_COLOR;
  border-color: #YOUR_NEW_COLOR;
}
```
