# 谷歌 Material Design 颜色系统

## 📋 官方颜色定义

所有图标颜色都遵循谷歌 Material Design 的官方颜色系统，与你的项目已有的设计系统完全一致。

### 核心色彩

| 颜色 | 十六进制 | RGB | 用途 | 备注 |
|------|---------|------|------|------|
| **Google Blue** | #1A73E8 | 26, 115, 232 | 主色、链接、主要操作 | 官方品牌色 |
| **Google Green** | #0F9D58 | 15, 157, 88 | 成功、正面反馈 | 绿色系 |
| **Google Yellow** | #FBBC04 | 251, 188, 4 | 警告、注意 | 黄色系 |
| **Google Red** | #E94335 | 233, 67, 53 | 错误、删除、危险 | 红色系 |
| **Google Gray** | #80868B | 128, 134, 139 | 禁用、次要文本 | 灰色系 |

## 🎨 颜色应用规则

### 1. Primary - Google Blue
```scss
主颜色：#1A73E8
深色变体：#1565C0
浅色背景：#D3F7FF
文本颜色：#014F5A
```

**应用场景：**
- 主要操作按钮
- 链接颜色
- 强调元素
- 活跃状态
- 主菜单项

**示例：**
```vue
<!-- 主操作按钮 -->
<button class="gm-btn-filled">
	<app-icon icon="download" color="primary" />
	下载
</button>

<!-- 导航链接 -->
<a style="color: #1A73E8">
	<app-icon icon="directions" color="primary" size="sm" />
	路线导航
</a>
```

### 2. Success - Google Green
```scss
颜色：#0F9D58
浅色背景：#E6F4EA
```

**应用场景：**
- 成功状态提示
- 已完成操作
- 验证通过

- 可用/激活状态

```vue
</view>
```

```scss
颜色：#80868B
灰度：100%
透明度：38%
```

**应用场景：**


## 🔄 与项目设计系统的对应关系

你的项目 (`styles/google-maps.scss`) 已定义了这些颜色：

```scss
/* 项目中的定义 */
$brand: #007B8B;               // 主品牌色（深青）
$success: #0F9D58;             // Google Green ✓
$warning: #FBBC04;             // Google Yellow ✓
$danger: #E94335;              // Google Red ✓
$teal: #007B8B;                // Teal
```

**注意：** 项目中的主品牌色是青色 (#007B8B)，但图标系统使用的是谷歌官方蓝色 (#1A73E8)。这提供了更好的对比度和可访问性。

## 💡 颜色使用最佳实践

### ✅ 推荐做法

1. **一致性** - 在整个应用中统一使用这些颜色
```vue
<!-- ✓ 所有成功状态都用绿色 -->
<app-icon icon="check" color="success" />
<app-icon icon="done_all" color="success" />
```

2. **清晰度** - 在不同状态间清楚区分
```vue
<!-- ✓ 清晰的状态指示 -->
<app-icon icon="check" color="success" />      <!-- 完成 -->
<app-icon icon="pending" color="warning" />    <!-- 待处理 -->
<app-icon icon="error" color="error" />        <!-- 失败 -->
```

3. **对比** - 确保图标与背景有足够对比
```vue
<!-- ✓ 蓝色图标在白色背景上清晰 -->
<view style="background: white">
	<app-icon icon="search" color="primary" />
</view>
```

4. **可访问性** - 不仅依赖颜色传递信息
```vue
<!-- ✓ 结合文本和图标 -->
<view class="success-state">
	<app-icon icon="check" color="success" />
	<text>已保存</text>
</view>
```

### ❌ 避免做法

1. **混用颜色系统**
```vue
<!-- ✗ 不要混合使用多个颜色系统 -->
<app-icon icon="check" :custom-style="{ color: 'lime' }" />
```

2. **过度使用颜色**
```vue
<!-- ✗ 不要给所有图标都上色 -->
<app-icon icon="info" color="warning" />
<app-icon icon="help" color="error" />
<app-icon icon="settings" color="success" />
```

3. **忽视对比度**
```vue
<!-- ✗ 不要在相似背景上使用相似颜色 -->
<view style="background: #E6F4EA">
	<app-icon icon="check" color="success" />  <!-- 对比度不足 -->
</view>
```

## 🎯 实际应用示例

### 场景 1：订单状态指示

```vue
<view class="order-status">
	<!-- 已完成 -->
	<view v-if="order.status === 'completed'" class="status-item">
		<app-icon icon="check_circle" color="success" size="lg" />
		<text>已完成</text>
	</view>
	
	<!-- 待发货 -->
	<view v-else-if="order.status === 'pending'" class="status-item">
		<app-icon icon="pending" color="warning" size="lg" />
		<text>待发货</text>
	</view>
	
	<!-- 已取消 -->
	<view v-else-if="order.status === 'cancelled'" class="status-item">
		<app-icon icon="cancel" color="error" size="lg" />
		<text>已取消</text>
	</view>
</view>
```

### 场景 2：表单验证

```vue
<view class="form-field">
	<label>邮箱地址</label>
	<input v-model="email" @blur="validateEmail" />
	
	<!-- 验证通过 -->
	<app-icon
		v-if="email && isValidEmail"
		icon="check"
		color="success"
		size="sm"
	/>
	
	<!-- 验证失败 -->
	<app-icon
		v-else-if="email && !isValidEmail"
		icon="close"
		color="error"
		size="sm"
	/>
</view>
```

### 场景 3：操作按钮组

```vue
<view class="action-buttons">
	<!-- 主操作 - 蓝色 -->
	<button class="btn-primary">
		<app-icon icon="download" color="primary" size="sm" />
		下载
	</button>
	
	<!-- 次操作 - 蓝色淡色 -->
	<button class="btn-secondary">
		<app-icon icon="share" color="secondary" size="sm" />
		分享
	</button>
	
	<!-- 删除 - 红色 -->
	<button class="btn-danger">
		<app-icon icon="delete" color="error" size="sm" />
		删除
	</button>
	
	<!-- 禁用 - 灰色 -->
	<button class="btn-disabled" disabled>
		<app-icon icon="save" color="disabled" size="sm" />
		保存
	</button>
</view>
```

## 📊 颜色可访问性说明

所有谷歌官方颜色都符合 WCAG AA 无障碍标准（对比度 4.5:1 以上）。

| 颜色 | 背景 | 对比度 | 符合标准 |
|------|------|-------|---------|
| Google Blue (#1A73E8) | 白色 | 8.3:1 | ✅ AAA |
| Google Green (#0F9D58) | 白色 | 7.8:1 | ✅ AAA |
| Google Yellow (#FBBC04) | 白色 | 4.8:1 | ✅ AA |
| Google Red (#E94335) | 白色 | 6.2:1 | ✅ AAA |
| Google Gray (#80868B) | 白色 | 4.5:1 | ✅ AA |
