# 图标系统使用指南

## 概述

我们建立了一套优雅的 SVG 图标管理系统，让你可以高效地使用和维护图标，最小化添加/修改图标的成本。

## 核心文件

- **`utils/icons.js`** - 图标映射表，集中定义所有图标
- **`components/AppIcon.vue`** - 全局图标组件
- **`static/icons/`** - SVG 图标文件存储目录

## 使用方式

### 方式 1：直接使用 AppIcon 组件（推荐）

```vue
<!-- 基础用法 - 使用图标名称 -->
<app-icon icon="search" size="md" />

<!-- 自定义大小 -->
<app-icon icon="directions" size="lg" />

<!-- 可点击的图标 -->
<app-icon icon="call" size="md" clickable @click="handleClick" />

<!-- 自定义样式 -->
<app-icon icon="restaurant" :custom-style="{ opacity: 0.8 }" />

<!-- 不同颜色变体 -->
<app-icon icon="search" color="primary" />    <!-- 主色 -->
<app-icon icon="search" color="success" />    <!-- 成功绿 -->
<app-icon icon="search" color="error" />      <!-- 错误红 -->
<app-icon icon="search" color="disabled" />   <!-- 禁用灰 -->
```

### 方式 2：通过函数获取图标路径

```vue
<script setup>
import { getIcon, getCategoryIcon, getActionIcon } from '@/utils/icons.js'

// 获取单个图标
const searchIcon = getIcon('search')

// 获取分类图标（传入 type: food, view, toilet, shop, other）
const icon = getCategoryIcon('food')

// 获取操作按钮图标
const navIcon = getActionIcon('navigate')
</script>

<template>
  <!-- 使用路径渲染图标 -->
  <image :src="searchIcon" />
</template>
```

## AppIcon 组件属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `icon` | String | '' | 图标名称或完整路径 |
| `size` | String | 'md' | 预设大小：xs \| sm \| md \| lg \| xl |
| `width` | String/Number | '' | 自定义宽度（优先级高于 size） |
| `height` | String/Number | '' | 自定义高度（优先级高于 size） |
| `mode` | String | 'aspectFit' | 图片模式 |
| `color` | String | 'primary' | 颜色变体：primary \| secondary \| success \| warning \| error \| disabled \| inherit |
| `clickable` | Boolean | false | 是否可点击（会应用悬停/按下效果） |
| `customStyle` | String/Object | {} | 自定义样式 |
| `alt` | String | 'icon' | 无障碍标签 |


## 颜色变体系统

AppIcon 组件支持 7 种预定义的颜色变体，使用谷歌 Material Design 的官方颜色系统。

### 颜色变体对照表

| 变体 | 谷歌颜色 | RGB | 用途 |
|------|---------|------|------|
| `primary` | Google Blue | #1A73E8 | 主要操作、链接 |
| `secondary` | Light Blue | 浅蓝 | 次要信息 |
| `success` | Google Green | #0F9D58 | 成功、正面 |
| `warning` | Google Yellow | #FBBC04 | 警告、注意 |
| `error` | Google Red | #E94335 | 错误、删除 |
| `disabled` | Gray | 灰色 | 禁用、不可用 |
| `inherit` | Custom | 自定义 | 无处理 |

### 颜色变体详解

#### 1. `primary` - Google Blue（主色）
用于主要操作和重点信息。使用谷歌官方蓝色。
```vue
<app-icon icon="search" color="primary" size="lg" />
<button><app-icon icon="download" color="primary" />下载</button>
```

#### 2. `secondary` - Light Blue（次色）
用于次要信息和辅助操作。浅蓝色调。
```vue
<app-icon icon="info" color="secondary" />
<app-icon icon="help" color="secondary" />
```

#### 3. `success` - Google Green（成功）
用于表示操作成功、状态正常等正面信息。谷歌绿色。
```vue
<app-icon icon="check" color="success" />
<text>✓ 验证成功</text>
```

#### 4. `warning` - Google Yellow（警告）
用于表示需要注意的信息、潜在问题等。谷歌黄色。
```vue
<app-icon icon="alert" color="warning" />
<text>⚠ 待发货</text>
```

#### 5. `error` - Google Red（错误）
用于表示错误、失败、删除等负面操作。谷歌红色。
```vue
<app-icon icon="delete" color="error" />
<text>✕ 操作失败</text>
```

#### 6. `disabled` - Gray（禁用）
用于表示禁用的功能、不可用的操作。灰色处理。
```vue
<app-icon icon="save" color="disabled" />
<button disabled><app-icon icon="lock" color="disabled" />锁定</button>
```

#### 7. `inherit` - Custom（继承）
不应用任何颜色变换，用于完全自定义。
```vue
<app-icon icon="star" color="inherit" :custom-style="{ opacity: 0.5 }" />
```

## 添加新图标

添加新图标只需三步：

### 1. 将 SVG 文件放入 `static/icons/` 目录

将你的 SVG 文件放入 `static/icons/` 目录下，例如：`static/icons/favorite.svg`

### 2. 在 `utils/icons.js` 中新增图标映射

```javascript
export const ICONS = {
	// ... 现有图标
	favorite: '/static/icons/favorite.svg',  // 新增这一行
	// ... 其他图标
}
```

### 3. 在模板中使用

```vue
<app-icon icon="favorite" size="lg" />
```

**就这么简单！** 不需要修改任何其他地方。

## 批量替换现有的 emoji/字体图标

如果要将某个页面的 emoji 替换为 SVG 图标：

1. 找到要替换的 emoji，例如 `🔍`
2. 确定对应的图标类型（搜索、电话、导航等）
3. 使用 AppIcon 替换：

```vue
<!-- 替换前 -->
<text style="font-size: 28rpx;">🔍</text>

<!-- 替换后 -->
<app-icon icon="search" size="md" />
```


## 常见问题

### Q: 如何改变图标颜色？
A: SVG 图标的颜色由 `fill` 属性控制。你可以用 CSS 或自定义 SVG 的 fill 属性。

### Q: 可以对图标进行动画吗？
A: 可以！AppIcon 组件支持 CSS transition 和自定义样式，你可以轻松添加动画效果。

### Q: 如何使用不在 ICONS 中定义的图标？
A: 直接传入完整路径即可：
```vue
<app-icon icon="/static/img/custom-icon.svg" />
```

### Q: 性能如何？
A: SVG 图标相比字体图标或 emoji 加载更快，且能更好地支持响应式设计和暗黑模式。

## 最佳实践

✅ **推荐做法**
- 使用 AppIcon 组件而不是直接渲染 `<image>`
- 在 `utils/icons.js` 中集中管理图标映射
- 对相关的图标使用别名（如 `food` → `restaurant`）
- 为新增图标编写有意义的名称

❌ **避免做法**
- 硬编码图标路径在组件中
- 混用 emoji、字体图标和 SVG 图标
- 直接修改 SVG 文件名而不更新映射表
