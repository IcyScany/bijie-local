## 📖 快速示例

### 表单验证

```vue
<script setup>
import { ref } from 'vue'

const email = ref('')
const isValid = ref(false)

const validateEmail = () => {
	isValid.value = email.value.includes('@')
}
</script>

<template>
	<view class="form-field">
		<input v-model="email" @blur="validateEmail" />
		
		<!-- 验证通过 - 绿色 -->
		<app-icon v-if="isValid" icon="check" color="success" />
		
		<!-- 验证失败 - 红色 -->
		<app-icon v-else-if="email && !isValid" icon="close" color="error" />
	</view>
</template>
```

### 订单状态指示

```vue
<template>
	<view class="order-status">
		<!-- 已完成 - 绿色 -->
		<view v-if="order.status === 'completed'">
			<app-icon icon="check_circle" color="success" />
			<text>已完成</text>
		</view>
		
		<!-- 待处理 - 黄色 -->
		<view v-else-if="order.status === 'pending'">
			<app-icon icon="pending" color="warning" />
			<text>待发货</text>
		</view>
		
		<!-- 已取消 - 红色 -->
		<view v-else-if="order.status === 'cancelled'">
			<app-icon icon="cancel" color="error" />
			<text>已取消</text>
		</view>
		
		<!-- 不可用 - 灰色 -->
		<view v-else>
			<app-icon icon="archive" color="disabled" />
			<text>已归档</text>
		</view>
	</view>
</template>
```

```vue
	<text>已验证</text>

	:color="isEnabled ? 'primary' : 'disabled'"
	:clickable="isEnabled"
/>
```

```vue

<app-icon icon="icon" :custom-style="{ color: 'lime' }" />

<!-- 不要过度上色 -->
<app-icon icon="all_items" color="warning" />
<app-icon icon="everything" color="error" />

<!-- 不要忽视可访问性 -->
<app-icon icon="check" color="success" />  <!-- 应加上文本 -->
```

## 🎯 常见问题

### Q: 为什么用谷歌蓝色而不是项目的青色？
A: 谷歌蓝色 (#1A73E8) 提供了更好的对比度和可访问性，符合 WCAG AAA 标准。青色 (#007B8B) 主要用在项目的其他UI组件中。

### Q: 如何在自己的页面中使用这些颜色？
A: 简单！只需在 `<app-icon>` 中添加 `color` 属性：
```vue
<app-icon icon="check" color="success" />
```

### Q: 能自定义颜色吗？
A: 可以！使用 `color="inherit"` 结合 `custom-style`：
```vue
<app-icon icon="star" color="inherit" :custom-style="{ opacity: 0.5 }" />
```

### Q: 这些颜色是否与项目的设计系统一致？
A: 是的！除了主色外，所有其他颜色（绿、黄、红、灰）都与你的项目 `google-maps.scss` 中的定义完全一致。

### Q: 如何添加新的颜色变体？
A: 编辑 `components/AppIcon.vue` 的 `<style>` 部分，添加新的 CSS 类即可。
